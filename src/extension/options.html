Zoom inputs

Held while scrolling to zoom. Native browser zoom keeps its Ctrl combos unless this is set to Ctrl.

Warning: Firefox intercepts Alt+scroll for history navigation (mousewheel.with_alt.action defaults to 2) and never delivers the wheel event to page JavaScript. Gesture zoom will not work unless you change this pref to 0 or 1 in about:config.

Each hotkey is its own modifier + key combo. Keys are event.key values (e.g. +, -, 0). Hotkeys are disabled when focus is inside a text field, textarea, or content-editable area so you can type normally (e.g. + without triggering zoom in).

Appearance

Choose how the extension UI looks. "Device" follows your operating system's dark/light preference.

Defaults

Off by default: the extension never re-applies an old zoom without an explicit opt-in. Per-site toggles live in the popup.

Off by default: zooming out stops at 100%, like a trackpad pinch that starts at the page's real size. Enable to zoom out to 30% and letterbox the page.

Warning: Allowing zoom below 100% is experimental and may cause layout issues or broken scrolling on some pages.

How position: fixed / sticky elements behave under zoom.

Warning: Non-default fixed-element policies are experimental and may cause elements to behave unexpectedly or disappear on some pages.

Per-site settings

Per-site overrides. The crisp-text escape hatch reflows a site's page at the settled scale so text renders crisply, trading layout fidelity for sharpness — never on by default.

Reset settings

Restores every option (gesture modifier, hotkeys, policy, theme) to its default. Remembered zoom levels are kept.

Delete saved data

Removes saved zoom positions for all sites. Settings and per-site toggles are kept.

Removes every per-site override (enabled, memory, crisp text, policy, zoom). Global settings are kept.

Clears everything: settings, per-site overrides, and remembered zoom levels. The extension resets to a fresh install.
